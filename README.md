# OceanSense Mockup SPA

This project is a visual and interaction prototype that presents ideas and possibilities
for how data nodes and the federated data layer in the OceanSense scope can be facilitated.

## Current features
- Explorer dashboard with dataset discovery and inspector modes (form + JSON).
- Node Registry mock for configuring and reviewing federated nodes.
- Data Access & API documentation view with in-page navigation.
- Data Documentation workspace with explorer, wizard, and review flows.
- Guidelines page covering ingestion scenarios and documentation checklist.
- Connections map with labeled relationships and typed node icons.
- Mock login UI with persisted session state.

## Development
- Install deps: `npm install`
- Start dev server: `npm run dev`
- Build for production: `npm run build`
- Preview build: `npm run preview`
